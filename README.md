# Django News Application — Capstone Consolidation

This repository contains a Django news application with reader, journalist, and editor roles; article submission and approval; newsletters; subscriptions; and a token-authenticated REST API.

## Project layout

- `manage.py` — Django command-line entry point.
- `news_application/` — Django project settings and URL configuration.
- `news/` — models, forms, views, API endpoints, templates, static files, and tests.
- `requirements.txt` — pinned Python dependencies.
- `Planning/` — project design and testing notes.
